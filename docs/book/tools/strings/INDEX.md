# docs/book/tools/strings/ — Text of the book entries, one file per language

| Path | What | Read when |
|---|---|---|
| `en.json` | English text of every key used by `../data.py` and `../refresh.py`; the other files are checked against its keys | Adding a key |
| `es.json`, `ca.json`, `gl.json`, `eu.json`, `pt.json`, `sv.json`, `it.json` | The same keys in Spanish, Catalan, Galician, Basque, Portuguese, Swedish and Italian | Adding or correcting a translation |
