# TASK-0040 — Add locale CLDR library (plurals, UTC dates, numbers, language names) and optimize SCRAM PBKDF2/HMAC performance

## Goal (one sentence)
Implement the `locale` CLDR library (`src/main/ridgun/lib/locale.rg`) with cardinal plural rules, UTC date/datetime formatting, localized integer/decimal formatting, and language autonyms for `es`, `ca`, `eu`, `gl`, `pt`, `sv`, and `en`, and optimize `pbkdf2 hmac sha256`, `hmac sha256`, and `bitxor byte strings` in `src/main/ridgun/lib/crypto.rg` for SCRAM-SHA-256 authentication.
