# core-lessons-learnt-notes

Generated by `aix lessons index` from `lessons/*.md`. Never edit this file: add, merge or prune the lesson files with
`core-lessons-learnt`, then run `aix lessons index`. Each line is a rule; open its file for why and when it applies.
`person` lessons are one user's preference: apply them when that author is the one you work with.

- WHEN THE USER ASKS A QUESTION OR CHECKS STATUS, REPLY IMMEDIATELY IN VISIBLE TEXT WITHOUT LAUNCHING MORE TOOL CALLS FIRST. (project, gemini@local) [lessons/always-reply-immediately-to-user-questions.md](lessons/always-reply-immediately-to-user-questions.md)
- NEVER RUN OBJDUMP OR ANY BINARY DISASSEMBLY COMMAND ON EXECUTABLES OR SHARED LIBRARIES. (project, gemini@local) [lessons/no-binary-disassembly.md](lessons/no-binary-disassembly.md)
- NEVER USE PROT_EXEC MMAP PAGES, RAW MACHINE-CODE BLOBS, OR SHELLCODE-LIKE EXECUTION; WRITE ALL ALGORITHMS IN PURE RIDGUN. (project, gemini@local) [lessons/no-executable-machine-code.md](lessons/no-executable-machine-code.md)
- ALWAYS USE SPACE-SEPARATED TUPLE AND SEQUENCE TYPE SIGNATURES (`Int Int`, `[String String]`) INSTEAD OF COMMA-SEPARATED TUPLES (`(Int, Int)`). (project, gemini@local) [lessons/space-separated-tuple-signatures.md](lessons/space-separated-tuple-signatures.md)
- ALWAYS REFER TO THE ELEMENTS OF RIDGUN-LIBS AS LIBS RATHER THAN MODULES, RESERVING THE WORD MODULE FOR OTHER PURPOSES. (project, gemini@local) [lessons/use-libs-not-modules.md](lessons/use-libs-not-modules.md)
